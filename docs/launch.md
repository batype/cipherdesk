# 发布素材草稿

每天一个开源小工具，第003个：CipherDesk。

接口签名对不上？AES参数总少一个IV？JWT看到了内容，却不知道签名是否可信？

把AES、RSA、SM3/SM4、摘要、HMAC、JWT和编码转换放进一个本地工作台。支持亮暗模式，浏览器内处理，也可以用Node API和CLI调用。MIT开源。

在线：https://batype.github.io/cipherdesk/
源码：https://github.com/batype/cipherdesk

15秒演示：载入AES示例 → 开始加密 → 参数自动折叠 → 结果转输入 → 开始解密 → 切换暗色模式。强调“密文包保存IV等参数，密钥不在包里”。
